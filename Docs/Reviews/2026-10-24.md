## 审查发现与使用边界

### R-001：云端 Unity 搜索索引异常

- 级别：低。置信度：已确认。
- 证据：启动索引时出现 `ArgumentOutOfRangeException`；堆栈位于 `UnityEditor.Search.SearchDatabase.GetDefaultSearchDatabase` / `SearchInit.IndexationOnStartup`。
- 对比：PR #1 之前的基线、清理后的基线和当前验证具有相同堆栈。属于本次修改前已有的问题。
- 已观察影响：异常后素材检查和功能自检仍完成，Unity 退出码为 `0`。不能因此声称 Console 完全没有异常。
- 建议：先在本地相同 Unity 版本中复核搜索功能，保留日志；目前没有证据表明修改游戏脚本能解决此异常。

### R-002：恢复的素材预制体不包含完整示例行为

- 类型：开发使用说明。置信度：已确认。
- 7 个素材预制体移除了 12 个依赖旧示例 C# 的组件，4 个动画片段移除了 5 个旧示例回调；视觉资源、动画曲线和原有元数据保留。
- `EnemySample.prefab` 原本引用一个不存在的控制器，现使用已有的游戏敌人动画控制器。
- 部分素材预制体只保留对象结构或美术/物理组件。继续开发时需要挂接实际使用的行为脚本，不能把它们全部当作即放即用的角色或管理器。
- 现有 `Assets/Game` 内的游戏运行代码、场景、预制体和动画没有因此改变。

### R-003：仓库不包含持续自动验证入口

- 类型：验证能力限制。置信度：已确认。
- 本次自检使用工作区工程副本中的临时 Editor 验证脚本；辅助代码按工程精简目标未放入仓库。
- 仓库没有专用测试程序集或 GitHub Actions 工作流。声明了 Test Framework 依赖，不等于已有测试用例。
- 从 GitHub 新克隆工程后，不能直接运行已经移除的 `CourseworkPlayModeValidator.Run`。
- 建议：当前可使用下方清单手工复核。未来需要 CI 时，再单独引入可重复运行的测试，不把本记录当作持续测试通过证明。
