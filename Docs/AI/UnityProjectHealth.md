- 原始生成器仍生成最初的 7 敌人示例。当前手工关卡是 8 敌人版本，运行与导出使用当前场景，不调用原始生成器。
- 课堂目录中的地形素材仍被正式关卡使用，不能按“示例”名称全部删除。
- 三个渲染设置资源在同版本 Unity 导入时发生序列化更新，Unity 自动解析了传递依赖锁文件；未手动升级 manifest 中的直接包版本。
- 批处理 Play Mode 启动时观察到 UnityEditor.Search.SearchDatabase 的索引异常。本机 Error Pause 开启，该错误导致游戏在第 1 帧、游戏时间 0 自动暂停。验证器改为使用游戏时间等待，在批处理期间临时关闭自动暂停并保留错误日志，结束后恢复原设置（8071）；重新运行的游戏检查通过。该索引异常仍未修复，不能声称 Editor Console 完全无错误。Error Pause 的行为依据 [Unity ConsoleWindow 源码](https://github.com/Unity-Technologies/UnityCsReference/blob/master/Editor/Mono/ConsoleWindow.cs)。
- 未作手工完整通关、性能分析、其他平台构建、所有设备输入检查；没有已确认的存档或多人系统需要审查。
- 老师的评分与提交要求尚未提供；没有新增课程玩法或推断评分规则。
